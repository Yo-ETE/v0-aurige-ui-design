# Panneau UDS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Client UDS générique (session / security access / IOControl / RoutineControl / ReadDID) depuis le Pi, pour reproduire un test d'actionneurs de valise, l'utilisateur fournissant IDs/DID/clé.

**Architecture:** Backend `uds_client.py` (framing single-frame ISO-TP + décodage NRC) + `routers/uds.py` (`POST /api/uds/request`) réutilisant `main.obd_send_with_flow_control` (ISO-TP réception). Frontend : client + page `/uds` avec presets + confirmation sécurité sur les services d'action.

**Spec:** `docs/superpowers/specs/2026-10-03-uds-panel-design.md`

### Task 1: Backend — uds_client + router + tests

**Files:** Create `backend/uds_client.py`, `backend/routers/uds.py`, `backend/tests/test_uds.py` ; Modify `backend/main.py` (include), `backend/permissions.py`, `backend/tests/test_route_inventory.py` (regen), `backend/tests/test_integration_boot.py`.

**Interfaces:** `POST /api/uds/request`.

- [ ] `backend/uds_client.py` :
  - `NRC: dict[int,str]` (libellés FR, voir spec §3 : 0x10,0x11,0x12,0x13,0x22,0x24,0x31,0x33,0x35,0x36,0x37,0x78, …).
  - `def build_single_frame(service_hex: str, data_hex: str) -> str` : normalise hex (upper, sans espaces) ; `payload = service + data` (octets) ; `n = len(payload_bytes)` ; si `n > 7` → `ValueError("Requete multi-frame non supportee (>7 octets)")` ; retourne `f"{n:02X}{payload}".ljust(16,"0")` (pad 8 octets).
  - `def decode_response(responses) -> dict` : prend la valeur `responses` de `obd_send_with_flow_control` (réassembler en une suite d'octets hex ; gérer liste de trames / chaîne) → si vide `{raw:"", positive:False, data_hex:"", error:"pas de reponse"}` ; si `bytes[0]==0x7F` → `{raw, positive:False, service_echo:bytes[1], nrc:{code:bytes[2], label: NRC.get(bytes[2],"inconnu")}}` ; sinon `{raw, positive:True, service_echo:bytes[0], data_hex: reste}`.
- [ ] `backend/routers/uds.py` : `router=APIRouter()`, `import main`, `import uds_client`. Modèle `UDSRequest {interface:str, request_id:str, response_id:str="7E8", service:str, data:str=""}`. `POST /api/uds/request` :
  - valide interface ∈ {can0,can1,vcan0} (400) ; `request_id`/`response_id` `^[0-9A-Fa-f]{1,8}$` (400) ; `service` `^[0-9A-Fa-f]{2}$` (400) ; `data` `^([0-9A-Fa-f]{2})*$` (400).
  - `frame = uds_client.build_single_frame(service, data)` (ValueError→400).
  - `result = await main.obd_send_with_flow_control(interface, request_id.upper(), frame, response_id.upper())`.
  - si `not result.get("success")` → `{status:"error", error: result.get("error","transport")}`.
  - sinon `resp = uds_client.decode_response(result.get("responses"))` → `{status:"ok", request:{interface,request_id,response_id,service,data}, response: resp}`.
- [ ] `main.py` : `from routers.uds import router as uds_router` + `app.include_router(uds_router)` avant le rebind CORS.
- [ ] `permissions.py` : `("POST", r"^/api/uds/", ["can_inject"])`.
- [ ] `test_integration_boot.py` : `/api/uds/request` est POST mutant gardé `can_inject` (satisfait le check, NE PAS allowlister).
- [ ] `test_route_inventory.py` : régénérer EXPECTED (154→155).
- [ ] `backend/tests/test_uds.py` (login admin ; mock `main.obd_send_with_flow_control`) : `build_single_frame("2F","0203FF")` == `"042F0203FF0000"` zero-padded 16 (vérifier len/pad) ; service+data 8 octets → ValueError→400 ; positive (`obd_send` renvoie success + responses `6F0203FF`) → `response.positive True, service_echo 0x6F` ; négative `7F2F33` → `nrc {code:0x33, label contient "securite"}` ; `success False` → `{status:"error"}` ; interface/request_id/service invalides → 400.
- [ ] `cd backend && python -m pytest -q` vert (incl inventory 155, integration_boot) + `npx tsc --noEmit` 0. Commit `feat(uds): client UDS generique (ISO-TP) + endpoint request + decodage NRC`.
